# StyleKart — Myntra-inspired Fashion Store (Frontend Demo)

## Run the project
1. Extract the ZIP file.
2. Open the `Myntra_Style_Clone` folder in Visual Studio Code.
3. Install the **Live Server** extension if it is not already installed.
4. Right-click `index.html` and choose **Open with Live Server**.
5. The site should open in your browser.

You can also open `index.html` directly in a browser.

## Files
- `index.html` — page structure and content
- `style.css` — layout, colours, typography and responsive design
- `script.js` — product data, search, category filtering, sorting, wishlist and bag interactions

## Features
- Responsive navigation and mobile menu
- Search products by name, brand or category
- Filter products by category
- Sort products by price
- Add/remove wishlist items
- Add products to bag and view item count/total
- Newsletter form demo
- Product cards and promotional sections

## Important project scope
This is a frontend educational clone inspired by the layout and shopping experience of fashion marketplaces. It is not affiliated with Myntra. It does not include a server, database, user authentication, real checkout, payment gateway or order processing. Product images are loaded from Unsplash, so an internet connection is needed for those images and Google Fonts.
